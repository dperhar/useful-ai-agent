# Markdown Context

Use this when creating, updating, or auditing `.md` memory files.

Rules:

- Read `AGENTS.md` first.
- Use the routing table.
- Prefer updating existing files over creating new files.
- Keep timelines append-only unless explicitly rewriting.
- Add timestamps to durable facts.
- Cross-reference canonical files instead of duplicating facts.
