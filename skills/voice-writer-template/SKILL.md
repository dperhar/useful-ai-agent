# Voice Writer Template

Use this to create a user-specific writing skill.

Inputs:

- 5-20 representative writing samples.
- Channels and constraints.
- Words/tones to avoid.
- Examples of bad output.

Output:

- Voice principles.
- Structure patterns.
- Phrase bank.
- Anti-patterns.
- Review checklist.
