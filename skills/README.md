# Skills

These skills are installed into the user's harness workspace.

- `context-architecture-setup`: create lifecycle-split context.
- `context-architecture-cleanup`: audit routing, token bloat, orphans.
- `improve`: critique, improve, and reconcile outputs back into source files.
- `md-context`: maintain markdown memory.
- `telegram-agent-ops`: operate Nanobot/Telegram safely.
- `backup-governance`: backup and restore discipline.
- `memory-reconciliation`: keep MemPalace and markdown aligned.
- `voice-writer-template`: create a personal writing voice skill.
