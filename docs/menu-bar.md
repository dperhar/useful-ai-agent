# Menu Bar UX

The menu bar app is the nontechnical control surface.

## Required Actions

- Start harness.
- Stop harness.
- Restart harness.
- Run health check.
- Run encrypted backup.
- Open Telegram bot.
- Open local console.
- View logs.
- Update runtime.
- Re-run onboarding.

The app must not store secrets. It calls `useful-agent` commands and displays
redacted output.
