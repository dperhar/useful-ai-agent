# Manual Steps

Some steps cannot be automated safely.

## Telegram Bot

1. Open Telegram and chat with `@BotFather`.
2. Create a bot with `/newbot`.
3. Copy the token.
4. Enable group usage if you want group chats.
5. Enable Guest Chat Mode if you want mention-in-any-chat behavior.
6. Give the token to the local installer when prompted.

## macOS Permissions

Approve prompts for:

- Transcripted microphone/audio/screen capture, depending on your recording mode.
- Menu bar app automation permissions if macOS asks.
- Terminal or your agent app file access if it needs to write the workspace.

## AI App Login

Log into Codex, Cursor, Claude, or other AI apps manually. The harness does not
store or bypass subscription credentials.
