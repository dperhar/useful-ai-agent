# Governance Module

Health checks cover:

- Router files.
- Nanobot config and LaunchAgent.
- WebSocket local-only policy.
- MemPalace binary and palace.
- Transcripted captures.
- Backup vault.
- Disk pressure.
- Secret redaction.

Checks run manually, before backups, before updates, and from the menu bar.
There is no default recurring 10-minute background loop.
